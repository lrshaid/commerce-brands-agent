# Warehouse layer

BigQuery SQL templates use `{{project}}` and `{{dataset}}` placeholders. Staging expects a JSON column named `payload` in each raw table.

The returns fact implements the required full outer join and stores RMV negative. The recovered commercial-revenue document now supplies the business classification for product and warranty exchange lines, but not the raw Shopify field or landing contract needed to construct those lines. The daily mart therefore still leaves EMV and NMV null rather than silently treating missing exchange data as zero.
